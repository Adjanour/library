# Library v0.1.1-preview.1

This is a public preview of Library's local-first reading workspace.

## Recommended: Native Desktop Preview setup

Choose one small setup program:

| Platform | Download |
| --- | --- |
| Windows x86_64 | `library-setup-windows-x86_64.exe` |
| macOS Apple Silicon | `library-setup-macos-aarch64.zip` |
| macOS Intel | `library-setup-macos-x86_64.zip` |
| Linux x86_64 | `library-setup-linux-x86_64.tar.gz` |

Run the setup program without arguments. It detects the current platform,
downloads the matching native CEF desktop bundle, verifies the signed manifest
and payload checksum, installs into the current user's application-data
directory, creates a reusable launcher, and starts Library.

The Linux setup adds Library to the current user's application menu. The
macOS setup adds `Library.app` to `~/Applications`. Neither action writes to a
system-owned directory.

No account, separate Deno installation, administrator access, or `sudo` is
required. The setup binaries are under 1 MB. The native desktop payload is
larger because it includes CEF. The browser-only Web Preview downloads about
45 MB of verified runtime and application data.

Windows and macOS binaries are experimental and are not code-signed or
notarized yet. SmartScreen or Gatekeeper may display a warning. These builds
need native-device testing before the final `v0.1.1` release.

Checksums are published beside every setup binary. The release manifest is
signed in protected CI, and the corresponding public key is pinned inside the
installer.

## Explicit Web Preview setup

Run the setup command with `web-preview` when a browser-only installation is
preferred. It installs the private Deno runtime and opens Library at
<http://localhost:8080>.

## Manual Web Preview bundles

Contributors can use `library-web-v0.1.1-preview.1.zip` on Windows or
`library-web-v0.1.1-preview.1.tar.gz` on Linux and macOS. Manual bundles
require Deno 2.9.6 or newer on `PATH`. The setup programs above install their
own runtime and are the simpler testing path.

## Linux desktop build

`library-v0.1.1-preview.1-linux.tar.gz` is the larger Deno Desktop and CEF
build. Its SHA-256 digest is
`2b93b33fddb43a10ea0b3286c10d7a0b6b5dde7e4242d33c96946ee364c1f9a3`.
Extract it and run `app/app`.

The signed `library-web-preview-manifest.signed` manifest now carries both the
native Desktop Preview and explicit Web Preview packages. The `install-url`
command remains a development and legacy installation path.

## Included

- Full-text search, queue management, keyboard shortcuts, and settings
- EPUB reading with durable progress, preferences, diagnostics, and bounded caching
- PDF preview and reading with a 120 percent default zoom
- Configurable library folders that persist on the device
- Reading dashboard and progress tracking
- Cross-platform native Desktop Preview installer with CEF
- Explicit Web Preview installer with a private Deno runtime
- Signed manifests, verified downloads, version pointers, and cached artifacts
- Contributor, testing, packaging, and release-readiness guides
